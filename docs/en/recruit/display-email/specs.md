# Banner Specifications

## Formats and constraints

| Format | Dimensions (W × H) | Typical placement |
| :--- | :--- | :--- |
| **Large Banner** (Leaderboard) | **600 × 150 px** *(sometimes 640 px)* | Header or core of email, the most impactful |
| **Block** (Rectangle) | **300 × 250 px** | Side column or footer of email |

| Criterion | Specification |
| :--- | :--- |
| **File Type** | JPG, PNG, or GIF |
| **Color Mode** | RGB |
| **Maximum Weight** | 150 KB, recommended < **80 KB** for fast loading on mobile |

## Animated GIFs

:::warning First frame rule
Outlook 2007 to 2019 (Windows) only displays the first image. Put the main information and the Call-to-Action on the **first frame**.
:::

- **3 to 5 frames maximum**, for a simple loop and a light file.
- **Total duration of 2 to 4 seconds**, then stop on the frame carrying the offer and CTA.
- **No fast flashing**: it hurts readability.

| Client | Display |
| :--- | :--- |
| Gmail, Apple Mail, Yahoo, iOS/Android mobile, Outlook (web, Mac, mobile, new Outlook) | Full animation |
| Outlook 2021, 2024 and Microsoft 365 (Windows) | Full animation, unless Windows animations are turned off (first frame) |
| Outlook 2007 to 2019 (Windows) | First frame only |

## Design

:::tip White background: add a border
A banner with a white background blends into the email. Add a **1 px gray border** (`#cccccc`) around the visual.
:::

:::tip Mobile readability
On mobile, a 600 px banner is reduced to ~350 px wide. Avoid thin or small fonts: **recommended minimum 16 px**.
:::
