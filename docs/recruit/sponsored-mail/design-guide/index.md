# Guide de Conception

Au déballage, votre flyer a moins de 3 secondes pour convaincre.

::: tip En bref
- Quatre étapes : stratégie, création, légal, puis BAT validé par getinside avant toute impression.
- Six mécaniques, toutes avec un QR code. L'offre décide : valeur monétaire, valable 3 mois minimum, code promo unique par marque qui diffuse.
- Le scan se fait sur smartphone : landing page responsive, rapide et simple.
:::

## Stratégie & Mécaniques

Choisissez la mécanique selon votre objectif, puis posez-vous : **"Pourquoi ce contenu est-il destiné à cette audience ?"** La cohérence avec l'univers de la marque qui diffuse fait un flyer conservé plutôt que jeté.

| Mécanique | Quand la choisir | Exemple |
| :--- | :--- | :--- |
| **Promotion** | Conversion immédiate en ligne | « Scannez pour une offre exclusive » |
| **Drive to Store** | Trafic physique, ou hybride Web + magasin | « Un café offert en boutique » |
| **Contenu éducatif** | Image de marque, engagement long terme | « 5 recettes de saison » |
| **Jeux** | Leads qualifiés (multi-formats : [bundles](/recruit/bundles)) | « Flashez pour tourner la roue » |
| **Drive to App** | Acquisition d'utilisateurs mobiles | « Téléchargez l'app, gagnez des points » |
| **Feedback** | Connaissance client, avis vérifiés | « Votre avis contre un cadeau » |

## L'Offre : ce qui fait la différence

L'offre est la décision la plus importante : une bonne offre compense une mise en page moyenne. getinside est un **média non intentionniste** : seule la force de l'offre lève les derniers freins.

| Paramètre | Recommandation |
| :--- | :--- |
| **Type** | Valeur monétaire (« 10 € offerts ») ou produit offert, plutôt qu'un pourcentage |
| **Validité** | 3 mois minimum dès l'impression : les flyers sont gardés des semaines |
| **Code promo** | Unique par marque qui diffuse, court, avec son nom (« MARQUE20 »), sans `_`, `-`, `;` |

:::warning Réduction de prix : le prix de référence est obligatoire
Toute réduction annoncée (pourcentage, prix barré) impose d'afficher le **prix le plus bas pratiqué dans les 30 jours** précédents (directive Omnibus, DGCCRF). Une valeur offerte ou un cadeau n'est pas concerné.
:::

## Mobile First

L'expérience post-scan se fait à **99% sur smartphone**. Votre landing page doit être prête avant l'impression.

:::info 3 règles non négociables
1. **Responsive** : adaptée aux petits écrans.
2. **Rapide** : chargement immédiat, même en 3G/4G.
3. **Simple** : un formulaire court, un seul appel à l'action.
:::

## Copywriting & UX papier

- **Accroche :** le bénéfice client d'abord, pas votre marque.
- **QR code :** fond blanc, modules noirs, 14 × 14 mm minimum, instruction courte, en bas à droite ([spécifications](./print-specs)).
- **Aller plus loin :** [Anatomie d'un flyer performant](./best-practices).

## Questions fréquentes

::: details Une marque refuse mon visuel : que faire ?
La marque qui diffuse a un droit de veto sur la **marque** insérée (concurrent direct, catégorie incompatible), pas sur la direction artistique. Si votre fichier respecte les spécifications, il est conforme : transmettez votre BAT à [studio@getinside.fr](https://lp.getinside.fr/meetings/benoit-prentout), la validation getinside prime.
:::

::: details Comment suivre les performances de ma campagne ?
Votre espace getinside affiche les scans QR en temps réel et les volumes insérés (mis à jour chaque semaine). Ajoutez des paramètres UTM ([conventions](/recruit/analytics)) et un code promo unique par marque qui diffuse.
:::
