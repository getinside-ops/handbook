# Guide de Conception

Le déballage d'un colis est un moment à part. Le consommateur vient de recevoir quelque chose qu'il attendait : il est attentif, les mains occupées, l'esprit ouvert. Votre flyer a moins de 3 secondes pour en tirer parti.

De la stratégie créative à la validation technique : voici de quoi créer un flyer qui convertit.

:::warning Validation obligatoire
Aucun contenu n'est diffusé chez une autre marque sans validation préalable de getinside via la plateforme. Soumettez votre BAT numérique avant toute impression.
:::

## Stratégie & Mécaniques

Choisissez la mécanique adaptée à votre objectif. Toutes fonctionnent avec un QR code comme point d'entrée. Avant de valider votre choix, posez-vous : **"Pourquoi ce contenu est-il destiné à cette audience ?"** La cohérence entre l'univers de la marque qui diffuse et votre offre fait la différence entre un flyer conservé et un flyer jeté.

## L'Offre : ce qui fait la différence

L'offre est la décision la plus importante de votre flyer. Une bonne offre compense une mise en page moyenne. L'inverse est rarement vrai.

getinside est un **média non intentionniste** : en découvrant votre flyer, le consommateur n'avait pas prévu d'acheter chez vous. C'est la force de votre offre qui lève les derniers freins. Plus elle est généreuse, plus elle convertit. À vous de placer le curseur.

:::tip Privilégiez la valeur monétaire
**"10€ offerts"** convertit beaucoup mieux que "-10% de réduction". La valeur concrète est immédiatement perçue. Un produit offert ou un cadeau fonctionnent aussi très bien : le levier psychologique du cadeau surpasse celui de l'économie.
:::

:::info Durée de validité
Prévoyez une validité d'**au moins 3 mois**. Les destinataires conservent souvent les flyers plusieurs semaines avant de les scanner. Une offre expirée = une opportunité perdue.
:::

| Paramètre | Recommandation |
| :--- | :--- |
| **Type** | Valeur monétaire > pourcentage |
| **Durée de validité** | Minimum 3 mois à partir de la date d'impression |
| **Code promo** | Unique par marque qui diffuse, court, sans caractères spéciaux (`_`, `-`, `;`) |
| **Format du code promo** | Inclure le nom de la marque qui diffuse, ex : "MARQUE20" |

:::warning Annonce de réduction de prix : le prix de référence est obligatoire
Si votre flyer annonce une réduction (pourcentage, prix barré, "avant/après"), la loi française impose d'afficher le **prix de référence**, soit le **prix le plus bas pratiqué dans les 30 jours** précédant l'offre (directive Omnibus, contrôle DGCCRF). Une valeur monétaire offerte ou un produit cadeau n'est pas concerné, une raison de plus de les privilégier.
:::

:::tip Protégez votre marge
Calibrez l'offre selon votre marge et fixez une fenêtre de validité claire (minimum 3 mois). Une réduction généreuse mais bornée dans le temps convertit mieux qu'un rabais permanent qui habitue le client à attendre.
:::

## Mobile First

L'expérience post-scan se fait à **99% sur smartphone**. Votre landing page doit être prête avant l'impression.

:::info 3 règles non négociables
1. **Responsive** : la page doit s'adapter parfaitement aux petits écrans.
2. **Rapide** : le chargement doit être immédiat même en 3G/4G.
3. **Simple** : un seul formulaire court, un seul appel à l'action.
:::

## Copywriting & UX papier

**Accroche :** commencez par le bénéfice client, pas par votre marque. "Votre routine beauté offerte dans ce colis" > "Découvrez la nouvelle collection [Marque]".

**QR code** (voir les [spécifications techniques](./print-specs) pour les contraintes d'impression) :

- Fond blanc, module noir. Évitez les fonds texturés
- Taille minimum : **25 × 25 mm**
- Instruction courte à côté : "Scannez pour profiter de l'offre"
- Positionnez en bas à droite, là où le pouce tient naturellement le flyer

:::tip Aller plus loin
La hiérarchie du message, la structure recto/verso, le test des 3 secondes, la landing page post-scan et la boucle de mesure sont détaillés dans **[Anatomie d'un flyer performant](./best-practices)**.
:::

## Questions fréquentes

::: details Une marque refuse mon visuel : que faire ?
La marque qui diffuse a un droit de veto sur la **marque** insérée (concurrent direct, catégorie incompatible), mais pas sur la direction artistique. Si votre fichier respecte les spécifications techniques, il est conforme. Transmettez votre BAT à [studio@getinside.fr](https://lp.getinside.fr/meetings/benoit-prentout) pour validation officielle : la validation getinside prime sur l'appréciation subjective de la marque.
:::

::: details Comment suivre les performances de ma campagne ?
Votre espace getinside donne accès aux scans QR en temps réel et aux volumes de flyers insérés (mis à jour chaque début de semaine). Ajoutez des paramètres UTM à votre URL de destination pour le suivi dans Google Analytics ([conventions UTM](/recruit/analytics)), et un code promo unique par marque qui diffuse pour l'attribution offline.
:::
