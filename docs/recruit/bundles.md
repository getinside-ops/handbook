# Bundles & Media Kits

Un Bundle est un dispositif scénarisé qui active plusieurs inventaires d'une même marque partenaire en une seule opération : insertion colis, email, social, display. Une campagne isolée crée une exposition. Un Bundle crée un effet de présence qui améliore la conversion.

::: tip Vous diffusez les campagnes d'autres marques à vos clients ?
Vous souhaitez packager vos inventaires en Bundles ? Consultez le [guide Bundles côté Monétiser](/monetize/bundles).
:::

## Mécaniques disponibles

| Mécanique | Objectif principal |
| :--- | :--- |
| **Promotion** | Conversion directe via code promo ou bon de réduction |
| **Jeu concours** (Ticket d'Or, Roue de la Fortune, Quiz) | Leads opt-in, avec un code promo de consolation pour tous |
| **Contenu / Brand Content** | Notoriété et positionnement expert |
| **Drive to Store** | Trafic en point de vente physique |
| **Drive to App** | Installations qualifiées |
| **Feedback / Notation** | Collecte d'avis et panels consommateurs |

## Cadre RGPD du jeu concours

À l'inscription, le participant coche une case explicite :

> ☑ J'accepte de recevoir les offres commerciales du partenaire [nom de votre marque].

Seuls les participants ayant coché cette case vous sont transmis.

## Ce que vous fournissez

- **La dotation** : le produit d'appel qui attire les joueurs (par exemple *"Gagnez un an de produits"*). Vous gérez l'envoi aux gagnants après le tirage au sort.
- **Le code promo de consolation** : un code générique (par exemple `MERCI15`) offert à tous les participants.

Vous pouvez ajuster le contenu du dispositif (retirer un levier, modifier le volume) en discussion directe avec la marque partenaire.
