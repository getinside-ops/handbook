# Bundles & Media Kits

Un Bundle est un dispositif scénarisé qui active plusieurs inventaires d'une même marque partenaire en une seule opération : insertion colis, email, social, display.

::: tip En bref
- Un Bundle crée un effet de présence qui améliore la conversion.
- Vous fournissez visuels, dotation et code promo, la marque partenaire gère la landing page.
- Seuls les participants consentants vous sont transmis.
:::

::: tip Vous diffusez les campagnes d'autres marques à vos clients ?
Vous souhaitez packager vos inventaires en Bundles ? Consultez le [guide Bundles côté Monétiser](/monetize/bundles).
:::

## Comment ça marche

1. **Choisissez la marque partenaire et la mécanique.** Repérez le pictogramme "Offres Multi-leviers" dans le catalogue, puis la mécanique selon votre objectif.
2. **Fournissez les éléments.** Via la plateforme : visuels (logo HD, packshots), dotation, code promo de consolation. La marque partenaire crée la landing page co-brandée.
3. **Le dispositif tourne sur tous les canaux** en parallèle : flyers dans les colis, newsletter dédiée, bannières homepage, posts Instagram et TikTok.
4. **Récupérez les leads.** À la clôture, la marque partenaire transmet via getinside le CSV sécurisé des opt-ins. Importez-le dans votre CRM (Mailchimp, Klaviyo…) et envoyez **immédiatement** l'email de bienvenue avec le code promo promis.
5. **Jeu concours :** vous tirez au sort les gagnants des gros lots et gérez leur expédition.

## Performances

- **Leads opt-in qualifiés :** aucun perdant, code promo de consolation pour tous.
- **Mémorisation renforcée :** trois expositions (physique, email, social).
- **Engagement fort :** vous bénéficiez de la crédibilité de la marque partenaire.

::: tip Exemple terrain
AJY (marque bien-être) a obtenu 21,6 % de taux de scan avec un quiz "Découvrez votre Dosha", l'un des meilleurs scores du réseau.
:::

::: details Mécaniques disponibles
| Mécanique | Objectif principal |
| :--- | :--- |
| **Promotion** | Conversion directe via code promo ou bon de réduction |
| **Jeu concours** (Ticket d'Or, Roue de la Fortune, Quiz) | Leads opt-in, avec un code promo de consolation pour tous |
| **Contenu / Brand Content** | Notoriété et positionnement expert |
| **Drive to Store** | Trafic en point de vente physique |
| **Drive to App** | Installations qualifiées |
| **Feedback / Notation** | Collecte d'avis et panels consommateurs |
:::

::: details Cadre RGPD du jeu concours
À l'inscription, le participant coche une case explicite : « ☑ J'accepte de recevoir les offres commerciales du partenaire [nom de votre marque]. » Seuls les participants l'ayant cochée vous sont transmis.
:::

::: details Ce que vous fournissez
- **La dotation :** le produit d'appel (ex : *"Gagnez un an de produits"*), expédié par vous.
- **Le code promo de consolation :** générique (ex : `MERCI15`), offert à tous.

Le dispositif (levier, volume) s'ajuste avec la marque partenaire.
:::
