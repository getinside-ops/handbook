# Encart Newsletter (Display Email)

Insérez une bannière partenaire dans des emails que vous envoyez déjà. La création vient de la marque, vous ne produisez rien, et chaque envoi devient une source de revenu.

::: tip Vous voulez diffuser votre bannière ?
Vous souhaitez faire diffuser une bannière dans les newsletters d'autres marques ? Consultez le [guide Encart Newsletter pour Recruter](/recruit/display-email/).
:::

## Le principe

Vos newsletters et emails transactionnels (confirmation de commande, suivi d'expédition, relance panier) partent par milliers chaque semaine. Le Display Email ajoute un emplacement dans ces emails : la marque fournit la bannière, getinside vous transmet le bloc à intégrer, vous le placez dans votre routeur.

Vous restez maître de l'éditorial : vous choisissez les marques qui apparaissent, et une marque concurrente de votre activité ne passe jamais sans votre accord.

## Formats de bannières

| Format | Dimensions | Emplacement typique |
| :--- | :--- | :--- |
| **Leaderboard** (Bannière Large) | 600 × 150 px | Header ou cœur du mail |
| **Pavé** (Rectangle) | 300 × 250 px | Colonne latérale ou pied de mail |

:::tip Fond blanc : ajoutez une bordure
Si votre bannière a un fond blanc, ajoutez une fine bordure grise de 1 px (`#cccccc`) pour qu'elle ne se fonde pas dans l'arrière-plan de l'email.
:::

## Côté technique

L'intégration est légère : un bloc HTML ou une image à insérer dans le gabarit de votre routeur (Klaviyo, Brevo, Mailchimp, Splio, etc.). getinside fournit le visuel et le lien de tracking. Une fois l'emplacement créé, les campagnes suivantes réutilisent le même slot.

## Bonnes pratiques

- **Placez l'encart en cohérence avec votre contenu** : sous le corps principal de la newsletter, ou en pied d'email transactionnel, là où il ne gêne pas le message client.
- **Gardez une fréquence raisonnable** : un encart par email suffit. L'objectif est un revenu régulier, pas la saturation.
- **Déclarez vos envois** pour déclencher la facturation (voir le [guide d'intégration](./integration)).
