# Encart Newsletter (Display Email)

Insérez une bannière partenaire dans des emails que vous envoyez déjà : la marque fournit la création, vous ne produisez rien.

::: tip En bref
- Vous placez un bloc image + lien tracké dans votre routeur (Klaviyo, Brevo, Mailchimp, Splio…).
- Vous choisissez les marques qui apparaissent : aucune marque concurrente sans votre accord.
- Un encart par email suffit : un revenu régulier, sans saturer vos clients.
:::

::: tip Vous voulez diffuser votre bannière ?
Consultez le [guide Encart Newsletter pour Recruter](/recruit/display-email/).
:::

## Emplacements et formats

| Emplacement | Détail |
| :--- | :--- |
| **Emails transactionnels** (> 60 % d'ouverture) | Le plus premium : bannière « Offre Partenaire » dans les confirmations de commande ou de livraison |
| **Newsletters (Blast)** | Espaces libres de vos newsletters hebdomadaires |
| **Welcome emails** | Bannière dans la séquence de bienvenue automatisée |

| Format | Dimensions | Emplacement typique |
| :--- | :--- | :--- |
| **Leaderboard** (bannière large) | 600 × 150 px | Header ou cœur du mail |
| **Pavé** (rectangle) | 300 × 250 px | Colonne latérale ou pied de mail |

:::tip Fond blanc : ajoutez une bordure
Ajoutez une fine bordure grise de 1 px (`#cccccc`) pour que la bannière ne se fonde pas dans l'arrière-plan de l'email.
:::

## Intégration et bonnes pratiques

L'intégration est légère : un bloc HTML ou une image dans le gabarit de votre routeur. getinside fournit le visuel et le lien de tracking ; une fois l'emplacement créé, les campagnes suivantes réutilisent le même slot.

- **Placez l'encart sous le corps principal** de la newsletter, ou en pied d'email transactionnel, là où il ne gêne pas le message client.
- **Déclarez vos envois** pour déclencher la facturation (voir le [guide d'intégration](./integration)).
